# git リポジトリ名でプロジェクトを識別
$projectName = '_unknown'
if ($cwd -and (Test-Path $cwd)) {
    try {
        $gitRoot = & git -C $cwd rev-parse --show-toplevel 2>$null
        if ($LASTEXITCODE -eq 0 -and $gitRoot) {
            $projectName = Split-Path ($gitRoot.Trim()) -Leaf
        }
    } catch {}
    if ($projectName -eq '_unknown') {
        # git 管理外の場合はディレクトリ名を使用
        $projectName = Split-Path $cwd -Leaf
    }
}
$projectDir  = Join-Path $projectsBase $projectName   # Projects/my-project/

実装上の注意点

Windows 環境特有のハマりポイントと解決策。同じ問題は二度踏まない。

🔤
エンコーディング問題
PS5.1 は UTF-8 ファイルを CP932 として読む。対策:
  • PS1 ファイルは UTF-8 BOM 付きで保存
  • スクリプト本体に日本語テキストを書かない
  • [Console]::OutputEncoding = UTF8 を設定
🔐
claude CLI 認証
claude.exe --print は OAuth セッションを使う（APIキー不要）。ANTHROPIC_API_KEY 環境変数がなくても動作する。ただし事前に claude auth login が必要。
📦
PowerShell の配列問題
外部プロセスのパイプ出力は配列として返る。正規表現で JSON 抽出する前に ($rawLines -join "`n") で文字列に変換する必要がある。
🪝
ExecutionPolicy
Hook コマンドに -ExecutionPolicy Bypass が必須。これがないと PS スクリプトの実行が拒否される。async: true も忘れずに設定する。
