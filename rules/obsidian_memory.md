# Obsidian メモリシステム

## セッション開始時の必須手順

各セッションの最初に以下の2つのインデックスを読み込んでから作業を開始してください。

### 1. グローバル知識（必ず読む）

`C:\Users\USERNAME\OneDrive\ObsidianVault\ClaudeCode\_Global\Index.md`

全プロジェクト共通のパターン・注意点が蓄積されています。

### 2. プロジェクト固有知識（現在のプロジェクトのみ）

現在の作業ディレクトリから Git リポジトリ名を特定し、対応するインデックスを読み込む：

`C:\Users\USERNAME\OneDrive\ObsidianVault\ClaudeCode\Projects\<リポジトリ名>\Index.md`

**リポジトリ名の特定方法:**
- `git rev-parse --show-toplevel` でリポジトリルートを取得し、そのフォルダ名を使用
- git 管理外の場合は作業ディレクトリ名を使用

ファイルが存在しない場合（新規プロジェクト）はスキップしてください。

## 読み込んだ内容の活用方法

- **グローバルパターン**: 環境・ツール・言語に関わらず有効なアプローチを優先採用
- **グローバル注意点**: Windows/PowerShell/Claude CLI 等の共通ハマりポイントを事前回避
- **プロジェクトパターン**: このリポジトリで実績あるアプローチを優先
- **プロジェクト注意点**: このリポジトリ固有の落とし穴を回避
- **決定事項**: 過去に確定した方針・設計を尊重

## セッション終了

Stop Hook が自動的にノートを生成・保存します（手動操作不要）。
- グローバルな知見 → `_Global/Index.md` に追記
- プロジェクト固有の知見 → `Projects/<リポジトリ名>/Index.md` に追記
